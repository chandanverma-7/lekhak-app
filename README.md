# Lekhak.app

Secure, scalable AI content processing platform built with:

* Next.js + TypeScript
* NestJS backend
* BullMQ queue workers
* Redis + PostgreSQL
* Secure JWT cookie auth
* AI processing via local models (Ollama)
* Audit trails & AI governance features

This project is being built with production architecture, security-first design, and enterprise frontend standards.
